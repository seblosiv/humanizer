API Documentation

Introduction

The ClearCraft API provides programmatic access to text analysis and rewriting capabilities. All endpoints return JSON responses and follow RESTful conventions.

Base URL: http://localhost:8000

Health Check

GET /healthz

Check if the service is running.

Example Response:

{
  "status": "healthy",
  "version": "1.0.0"
}

Analyze Text

POST /api/analyze

Analyze text for readability metrics.

Request Body:

{
  "text": "Your text to analyze here."
}

Response:

{
  "metrics": {
    "flesch_reading_ease": 65.2,
    "flesch_kincaid_grade": 8.1,
    "gunning_fog": 10.3,
    "smog_index": 9.5,
    "sentence_count": 5,
    "avg_sentence_length": 15.2,
    "avg_word_length": 4.8,
    "mtld": 52.3,
    "ttr": 0.75,
    "unique_words": 45,
    "total_words": 60,
    "passive_ratio": 0.20,
    "repetition_ratio": 0.05
  },
  "warnings": [
    "High passive voice usage (20%). Consider using more active voice."
  ]
}

cURL Example:

curl -X POST http://localhost:8000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Your text here."}'

Rewrite Text

POST /api/rewrite

Rewrite text for improved clarity and readability.

Request Body:

{
  "text": "Your text to rewrite here.",
  "tone": "neutral",
  "target_sentence_length_min": 14,
  "target_sentence_length_max": 22,
  "max_change_ratio": 0.30,
  "similarity_min": 0.92,
  "enable_llm": false,
  "enable_disclosure": true
}

Parameters:

Parameter Type Default Description
text string - Text to rewrite (required)
tone string "neutral" neutral, academic, or conversational
target_sentence_length_min integer 14 Minimum avg sentence length
target_sentence_length_max integer 22 Maximum avg sentence length
max_change_ratio float 0.30 Maximum allowed change ratio (0.0-1.0)
similarity_min float 0.92 Minimum semantic similarity (0.0-1.0)
enable_llm boolean false Enable LLM polish (requires API key)
enable_disclosure boolean true Add disclosure message

Response:

{
  "original_text": "The report was written by the team.",
  "rewritten_text": "The team wrote the report.\n\n---\n*Edited with AI assistance.*",
  "original_metrics": { /* ReadabilityMetrics */ },
  "rewritten_metrics": { /* ReadabilityMetrics */ },
  "changes": [
    {
      "pass_name": "voice_active",
      "tokens_changed": 2,
      "confidence": 0.75,
      "reason": "passive_by_agent",
      "similarity_score": 0.95
    }
  ],
  "overall_similarity": 0.94,
  "total_change_ratio": 0.18,
  "disclosure_added": true
}

cURL Example:

curl -X POST http://localhost:8000/api/rewrite \
  -H "Content-Type: application/json" \
  -d '{
    "text": "The report was written by the team.",
    "tone": "neutral",
    "enable_llm": false
  }'

Error Responses

400 Bad Request:

{
  "detail": "Text too long: 60000 characters > 50000 (max allowed)"
}

403 Forbidden (Disallowed Intent):

{
  "detail": "Disallowed intent detected: 'bypass' - ClearCraft does not support bypassing AI detectors."
}

500 Internal Server Error:

{
  "detail": "Analysis failed: Unexpected error occurred"
}

Limits & Constraints

  • Max Text Length: 50,000 characters (configurable)
  • Max Change Ratio: 30% (configurable)
  • Min Similarity: 92% (configurable)
  • Request Timeout: 120 seconds

Python SDK

For Python applications, you can use the native API instead of HTTP requests: 

from clearcraft.selector import TextSelector

# Initialize
selector = TextSelector(enable_llm=False)

# Rewrite text
result = selector.rewrite(
    text="Your text here",
    tone="neutral"
)

print(result.rewritten_text)
print(f"Similarity: {result.overall_similarity:.1%}")
